# 路线图

## 版本策略

语义化版本：`MAJOR.MINOR.PATCH`

- `MAJOR`：架构级重构或数据格式不兼容变更
- `MINOR`：新功能
- `PATCH`：修复、界面微调

---

## v0.2.0 — 当前（WebView 壳）

- [x] DNS 广告过滤（真机验证）
- [x] 教务直达（课表/成绩/选课，真机验证）
- [x] Material 3 界面
- [x] 网页移动端适配

**定位**：能用的工具。数据不在本地，每次联网。

---

## v1.0.0 — 原生课表（里程碑）

**目标**：打开即课表，断网可用。

### 核心

- [ ] `Timetable` 数据模型 + `timetable.json` 存储
- [ ] `TimetableView` 原生周课表网格（7 列 × 节次行，课块跨行）
- [ ] `JwglxtFetcher`：从正方课表页 DOM 提取结构化数据
- [ ] `SyncController`：编排 WebView 会话内同步
- [ ] 「下一节课」今日卡片
- [ ] 课表点击详情 BottomSheet

### 课表自定义（重点）

- [ ] 手动添加课程（实验课、教务不收录的课程）
- [ ] 编辑 / 删除课程
- [ ] 手动课程标记 `source=custom`，同步时永不删除
- [ ] 课程颜色选择（8 色板）
- [ ] 周次范围设置（支持单周、双周）

### 数据互通

- [ ] 课表导出 JSON → `Download/Tangli/`
- [ ] 课表导入 JSON（含版本校验与冲突策略）

### 其他

- [ ] 设置页：教务登录状态卡片
- [ ] 设置页：同步管理入口
- [ ] 首次启动引导（空态 → 引导同步）

**验收标准**：飞行模式下打开 App，课表正常显示。

## v2.0.0 — 多校兼容

**目标**：任何用正方/URP 教务的学校都能用。

- [ ] `CampusFetcher` 接口抽象完成
- [ ] `UrpFetcher`：URP 教务系统支持
- [ ] 学校选择向导（首次启动选择学校）
- [ ] 每校独立的 `default-targets.json` 模板
- [ ] 抓取失败的降级：纯手动模式（任何学校可用）
- [ ] 社区贡献机制：用户可提交自己学校的抓取配置

**技术前提**：`DATA-SCHEMA.md` 的数据结构对学校无感知，切换学校只换 Fetcher。
