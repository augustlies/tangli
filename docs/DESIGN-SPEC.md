# 界面设计规范

## 视觉基调

**原生优先，克制的现代感。** 目标用户是每天打开几十次看课表的学生，界面首要任务是「看一眼就知道下一节课在哪」，而不是炫技。

### 设计原则

1. **信息优先**：课表网格占满首屏，不浪费空间在标题和说明文字上。
2. **零等待**：所有列表数据来自本地，不出现 loading 骨架屏（同步时才出现）。
3. **一致性**：四个 Tab 共用同一套卡片、圆角、间距、色彩规则。
4. **跟随系统**：字体用系统默认（用户开了楷体就显示楷体），不强制覆盖。
5. **浅色为主**：v1 不做深色模式，但所有颜色通过主题 token 引用，为未来留口。

## 色彩

### 基础色板（不依赖动态取色时的兜底值）

| Token | 值 | 用途 |
|---|---|---|
| `surface` | `#F4F6FA` | 页面背景 |
| `surface-card` | `#FFFFFF` | 卡片背景 |
| `outline` | `#E8EAEE` | 卡片描边（`1dp`） |
| `on-surface` | `#14171F` | 主文字 |
| `on-surface-variant` | `#5A616E` | 次要文字 |
| `primary` | `#2563EB` | 主色（按钮、选中态、强调） |
| `primary-container` | `#E4ECFE` | 主色容器（浅底强调） |
| `error` | `#BA1A1A` | 错误、不及格 |
| `success` | `#146C2E` | 通过、已开启 |

## 圆角与间距

| 元素 | 圆角 |
|---|---|
| 大卡片（页级容器） | `22dp` |
| 普通卡片（列表项） | `18dp` |
| 课表色块 | `10dp` |
| 按钮（胶囊） | `26dp` |
| 输入框 | `14dp` |

**间距**：页面左右边距 `18dp`，卡片内边距 `16dp`，卡片间距 `12dp`。

---

## 字体

**使用系统默认字体族**（不指定 `fontFamily`，跟随用户系统设置）。

| 层级 | 字号 | 字重 |
|---|---|---|
| 页面大标题 | `24sp` | bold |
| 卡片标题 | `15sp` | bold |
| 正文 | `13sp` | regular |
| 辅助说明 | `12sp` | regular |
| 大数字（GPA / 分数） | `28sp` | bold |
| 课表课名 | `10sp` | medium |
| 课表教室 | `9sp` | regular |

> 数字（GPA、分数、节次、时间）建议用 `sans-serif` 等宽变体，避免跳动。

## 各页面布局

### 1. 课表页（默认首页）

```
┌────────────────────────────────┐
│ 第8周 · 周五        [↻ 同步]    │  ← 顶部条，32dp 高
├────────────────────────────────┤
│ ┌────────────────────────────┐ │
│ │ 下一节课                    │ │  ← 今日卡片（深色渐变）
│ │ 地学信息三维可视化           │ │
│ │ 10:10  ·  教302            │ │
│ └────────────────────────────┘ │
├────────────────────────────────┤
│ 一  二  三  四  五  六  日       │  ← 星期头
├────────────────────────────────┤
│ ┌──┬──┬──┬──┬──┬──┬──┐        │
│ │  │  │  │  │  │  │  │        │  ← 原生网格
│ ├──┼──┼──┼──┼──┼──┼──┤        │
│ │  │██│  │  │██│  │  │        │
│ ├──┼──┼──┼──┼──┼──┼──┤        │
│ │  │██│  │  │██│  │  │        │
│ └──┴──┴──┴──┴──┴──┴──┘        │
│                                │
│              [+ 添加课程]       │  ← 浮动按钮
└────────────────────────────────┘
```

- 顶部条：左侧「第 N 周 · 周X」，右侧同步按钮（显示上次同步时间）
- 今日卡片：显示今天/下一节课程；无课时显示「今日无课」
- 网格：`7 列 × N 行`（行 = 节次），课块跨行显示
- 点击课块 → BottomSheet 详情（课程名、教师、周次、节次、备注、编辑/删除）
- 浮动按钮：手动添加课程

## 交互约定

| 场景 | 行为 |
|---|---|
| 同步中 | 顶部进度条细分段，不遮挡课表 |
| 同步失败 | Toast「同步失败，本地数据已保留」，不清空 |
| 会话失效 | 自动打开 WebView 引导重新登录 |
| 添加课程 | BottomSheet 表单：课程名、地点、教师、星期、节次、周次、颜色 |
| 删除课程 | 长按或在详情页删除，二次确认 |
| 导出 | 存到 `Download/Tangli/timetable_<日期>.json` |
| 导入 | 系统文件选择器，解析失败提示具体原因 |

## 不做的事

- 不做深色模式（v1）
- 不做横屏课表（锁定竖屏足够）
- 不做小组件（后续版本考虑）
- 不做动画炫技（只保留 Material 默认的水波纹与转场）
