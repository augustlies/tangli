# 烫梨

东华理工大学的非官方校园小工具：**看课表、查成绩、和同学约空闲时间，顺手把烦人的开屏广告挡掉。**

课表和成绩同步一次就存在手机里，没网、离开校园网也能秒开。烫梨不保存你的账号密码。

[**⬇ 下载最新版**](https://github.com/augustlies/tangli/releases/latest) · [问题反馈](#问题反馈) · [更新日志](CHANGELOG.md)

## 能做什么

### 📅 课表
- 一屏看完一整周，左右滑动切换周次，打开就是现实中的这一周
- 正在上的课会高亮，时间线告诉你现在几点、下节课在哪
- 同一时间段有两门课时会并排显示，不会互相盖住
- 可以手动加课、改课，作息时间、显示五天还是七天都能调
- 在统一门户登录一次，之后点「同步」就在后台更新，不用再跳网页
- 课表太久没同步、登录过期时会提醒你

### 🎓 成绩
- 按学期查看成绩和绩点
- 出了新成绩会发通知（大约每 6 小时检查一次，可以关掉）
- 新出的成绩会打上小红点

### 👫 同学
- 生成二维码或分享码，把课表发给同学（只包含课程名、教室、时间，不含老师和学号）
- 扫码或粘贴就能导入同学的课表
- 一键算出你和一位或几位同学的**共同空闲时间**，约饭约自习不用再一节节对

### 🏫 校园
- **校历**：现在是第几周、离放假还有几天、本学期的考试周和假期，也能查看官网原图
- **校园地图**：南昌校区卫星图，离线可看，双指放大
- **图书馆预约**、**校园邮箱**入口

### 🛡 广告过滤
- 在手机本地过滤广告域名，闪动校园等 App 的开屏广告和弹窗广告会被挡掉
- 规则来自作者自己整理的名单，再加上开源项目 [anti-AD](https://github.com/privacy-protection-tools/anti-AD)，共约 10 万条
- 只处理域名查询，不经过任何服务器，也不碰你的其他网络流量

### ⚙️ 其他
- 深色模式（跟随系统 / 浅色 / 深色）
- 课表可以导出到手机日历，也能备份成文件换机恢复
- 设置 → 关于里可以检查更新、跳转到本项目

## 安装

1. 打开 [Releases 页面](https://github.com/augustlies/tangli/releases/latest)，下载最新的 `tangli-x.x.x.apk`
2. 在手机上打开安装，系统提示「未知来源」时允许一次即可
3. 以后有新版本，烫梨会在打开时提醒你

> 需要 Android 7.0 及以上。打开广告过滤时，系统会提示烫梨要建立 VPN，这是本地过滤用的，数据不会离开你的手机。

## 说明

- 烫梨是学生个人做的非官方工具，与东华理工大学无关
- 课表、成绩等数据以学校教务系统为准，绩点计算仅供参考
- 不保存账号密码，所有数据只存在你自己的手机里
